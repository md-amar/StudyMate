# Deployment Guide

## Local deployment

For local development:

```bash
node dev-server.js
```

The application is available at:

```text
http://localhost:3000
```

## Vercel

The repository supports a Vercel-style development workflow:

```bash
npx vercel dev
```

The repository also contains Vercel-specific project configuration generated by the Vercel CLI. The `.vercel` directory is intentionally ignored by Git and does not need to appear in the GitHub repository.

## AI configuration

The local default is:

```env
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
```

Do not assume these values will work for a public deployment.

A public deployment needs an AI endpoint reachable by the deployed backend.

## Deployment checklist

Before deploying:

- confirm the application loads
- confirm normal dashboard navigation
- confirm timetable functionality
- confirm notes functionality
- confirm exam functionality
- confirm AI Planner UI
- verify the AI backend endpoint
- verify environment variables
- confirm the configured Ollama model exists
- test error states, not only successful generation
- never commit `.env` files or credentials
